# AI Assistant & Explanation Module (Phase 5)

This directory is reserved for Phase 5 implementation of natural language financial questions, pattern explanations, and insight summaries.

## Planned Architecture:
- `intent.ts`: Parser mapping natural language queries to structured finance queries
- `explain.ts`: Natural language explanation generators relying strictly on deterministic database numbers
- `insights.ts`: Anomaly detection and spending trend notifications
- `rules.ts`: Safeguards ensuring AI never invents or calculates raw financial numbers directly
